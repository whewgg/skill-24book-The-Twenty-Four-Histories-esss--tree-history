# 猜谜／人物辨识规程（ershisishi-wenbai）

> 本文件是 `SKILL.md`「回答规范」中**猜谜与人物辨识**那一节的完整规程，由 2026-09-29（批次 1）整体外移。
> 触发场景：用户给出若干条线索问「这是谁／哪个皇帝／哪个人」，或给出人名问「这人的字号／事迹／谥号」。
> `SKILL.md` 正文只保留判据与指针；**一旦确认是人物辨识题，先读本文件再动手**。

## 0. 总纲：判的不是"谁最像"，是"别人为什么都不行"

- 答案的唯一性，由**其余合格者全部出局**证明，不是由"我这一个证起来了"证明。
- **答「无法唯一确定」是合规作答，不是失败**；给一个"某条不符的人"才是失败。
- ⚠ **「有据」≠「可答」**：检索到原文只证明该条线索存在，**不证明候选是唯一解**。
  「无据即止」管的是"零命中"，管不了"有命中但候选选错"——后者才是翻车主场。

## 1. 五类病根（每一条都是真翻车换来的）

| # | 病根 | 表现 |
|---|---|---|
| ① | **话题惯性** | 前几题都在十六国，就把「北方政权」默认成十六国，**完全不去检索金／蒙古** |
| ② | **循环论证** | 拿**已选答案**或其亲属／事件词当检索词——"拿答案搜答案，再用搜到的东西证明答案" |
| ③ | **改写题面** | 出现「宜按…理解／题面或有误／需宽松解读」这类**替候选打补丁**的措辞 |
| ④ | **把候选栏当结论** | `★` 只代表 `03-人物出现索引.md` 立过目，**不代表本段真是他** |
| ⑤ | **零命中凭记忆解释** | 被问的名词全库零命中，却用训练记忆写一段"听起来对"的解释 |

- ⑤ 的变体：**名词解释最容易被误当成「可以用常识答」，是幻觉高发区**。零命中只能答「本库未载」并列出检索词。
- 用户主动告知的**库外信息**（如「戒石铭原名《令箴》」）**可标注来源后接受**，但不得转而当作本库证据。
- ⚠ **时代错位**也要留意：孟昶作《令箴》、宋太宗命名「戒石铭」分属两代，**把宋名安到孟昶头上＝每一半都真的假话**。

## 2. 规程（四步，不许跳）

1. **检索**：`rag.py 谜 <独有引语／硬锚／特征词…>` —— **候选必须取自它的输出**（候选＝语料原文里真实出现的人名，并附"锚度"）。
   **不得先自己想名字**；从记忆里挑几个熟名字，等于没查。
2. **穷举**：对要判的线索，用**硬特征词** `rag.py <词> --top 0 --excerpt 60` 拉全库出处，**逐条判主语**，得到**合格者全集**。
3. **对照**：对每个候选跑 `rag.py 对照 <名> <线索1> <线索2> …`，逐条 ✔／✗／△ 与出处；**✗（硬锚对不上）即排除该候选**，反证栏写进答案。
   两个候选都"像"时，**比谁的出局条数多**，逐条写明死在第几条。
4. **定案**：照证据块 Read 原文；引用前过 `rag.py verify`。**单轮筛选后直接定案＝不合格**。

## 3. 检索路径按"手上有名字没有"分岔

- **有名字**（问这人的事迹／字号／仕历）→ `python tools\rag.py <人名> --fast` 取 ★本传，照证据块答。
- **没名字（「这是谁」）→ 不得拿待猜的名字当检索词**，改走 **「独有引语反查」**：从题干里挑**最不可能与人重名的措辞**直接搜库。
  优先序：① **独有引语／罕见专名** ② **庙号＋谥号** ③ 独有官名／封号／地名。
  实测 `python tools\rag.py "当并驱于中原"` → 全库候选 **1** 个文件，即《晋书·卷一百五·载记第五》石勒本传。
- ⚠ **庙号／谥号是硬锚，不是软特征**：可穷举、可判否，**对不上即一票否决**
  （石勒＝《晋书·卷一百五》「伪谥明皇帝，庙号高祖」；拓跋珪＝太祖／道武）。
- ⚠ **题干每条特征都须在原文里找到对应，一条不符即否决该人**，不得以"整体很像"结案。
- ⚠ **禁止先定答案再补理由**：出现「某人也算出身卑微……」这类替已选答案找补的话，即为翻车信号——**退回检索**。

## 4. 穷举的三条硬约束

- **合格者全集只有一个机械来源**：硬特征词 `--top 0 --excerpt 60` 全库穷举，逐条判主语（谁被这么评的），对上了才入列。
  "只交一个全对的人"不算解出——**其余合格者必须逐个判否**。
- **穷举结果不得再用关键词二次过滤**：同一线索的**措辞会变**，拿几个词（君天下／人主…）去 grep 穷举结果，
  就会漏掉《资治通鉴》卷 89「**相国轻佻**」这类写法，**把符合线索的人误判为不符合**。
  ⚠ **假阴性会错杀正确答案，比假阳性更致命**。
- **默认 `--top 8` 不是全集**：榜尾「⚠ 另有 N 段没显示」＝**还没穷举**；**榜上没有 ≠ 库里没有**。

## 5. 五类假锚（工具的黑历史，读候选栏前先知道）

| # | 假锚 | 实测 |
|---|---|---|
| ① | **候选缺人** | `谜` 的候选取自 `03`；`03` 按"有字／名入篇名"立目，陈玉成／石达开一批人全库 10–160 处而 `03` 曾**零条目**，谜面是此人原文时候选栏却顶出塔齐布／彭玉麟 |
| ② | **引文在库 ≠ 说话人是他** | 旧 `verify` 只看引文在不在库里，把魏徵的话写成「《旧唐书·卷七十一》李勣传载，勣对曰」照样 rc=0 放行 |
| ③ | **候选栏混着撞词词组与截短形** | `★ 国事`（真身是明史《练国事传》，`02` 建索引时把姓氏炸掉）、`★ 李瀚`／`★ 刘松`／`★ 松山`（实为李瀚章／刘松山） |
| ④ | **无「曰」的史文引用** | 「曹操，史载其『目有疾』」：三字短句旧闸抽不到（引文正则要 ≥4 字），而全库「目有疾」只有《梁书·萧恢传》两处，与曹操无关 |
| ⑤ | **名与帝号配错** | 「祖父刘宏（汉顺帝）」——刘宏是东汉孝灵帝，汉顺帝是刘保 |

五处已分别堵上：`谜` 另列「○ 段内句首主语」栏并写明**「不在候选」≠「不是答案」**；
`verify` 加**说话人归属闸**、**字号断言闸**、**归因闸**（史载／史称＋短引语，主语取引文前 24 字内最近的人名，帝王本名从 `07` 补进人名表）与**帝号闸**（「名（某帝）」回查 `07`）；
`谜` 的候选加了**频率闸**（≥250 卷即词组）、**截短形折叠**（同段每次出现都嵌在更长的人名里 ⇒ 不列），并在每行印 `03 N 卷` 让撞词露馅。

## 6. 读 `谜` 输出的规矩

- **行序＝离线索的字数由近到远**（并列时看离硬锚的距离、再看段内次数）。**排第一只说明"他贴着题面"，不是裁决**。
- **末行「距 N 字」是最小距离**——离得远的真人照样可能正确
  （实测：`谜 轻佻 靳准 长安` 首行「刘粲·距 2 字」为正解，而 司马模 距 64／袁绍 距 134 是本卷常遇撞词）。
- **括号里 `03 N 卷`** ＝ 这词全库有多"常用"；卷数越大越可能只是撞词（阈值 250 以上的词组已被工具自己滤掉，
  被折掉的截短形会另起一行如实交代）。
- **`★` 只代表"`03` 立过目"**。凡要写进答案的人名，必须用 `对照 <名> <线索…>` 过一遍全部硬锚，且落笔前 `verify`。
- **出现在「○ 段内句首主语」栏的，是 `03` 没立目的人——没进候选不等于排除**，得 `locate <名> --first` 现扫才知道。
- 被"折叠／备查"挤掉的，**不得当成排除依据**。

## 7. 落笔前的四锚自查（缺一即改答"无法确定"）

1. 这个名字在库里有**开传式起句**吗——`python tools\rag.py locate <名> --first` 给结论与起读行
   （⚠ 选项写在词前也认，但别写成 `locate --first` 后不跟名字）。
2. 引文命中处**确实是这个人**吗——跑 `verify`，说话人归属闸与归因闸会拦。
3. 字号／封号／帝号指得出 `02`／`07` 的条目或原文行吗（「名（某帝）」与 `07` 的号必须一致）。
4. 题干每条**硬锚**逐条 ✔，**且至少写出一条"题面与该人不符"**了吗。
   ⚠ **全打勾＝没真核对**：凡真查过库，被排除的候选必然有对不上的条目
   （曾把题面「农民家庭」偷改成「出身将门」去硬凑郭子仪，7 条全打勾、零出处，实为岳飞）。

- ⚠ **四锚自查是"落笔前的强制动作"，不是备查清单**：三道人物题我都**读到了它却没跑**，
  且**三次都做了它明令禁止的动作——改写题面**（"死需宽松解读"／"题面或有偏差"／"宜按前锋都督理解"）。
- **机械口径**：答复里必须**显式写出** ①候选的开传式起句 ②`verify` 结果 ③**"题面与候选不符的那一条"**；
  **写不出③ ⇒ 四锚不齐 ⇒ 改答"我查到 N 个候选，无法唯一确定"**。
- **尤其禁止"改写题面"**：线索说"祖父是诗人"，答成"虽非大诗人，但本人善诗"＝**这条线索不匹配**，不是可以打折的次要项。
- **禁止把封号（英王／忠王）、族属（羯人）、出身（农家）这类软特征当身份凭据**——那是人物瞎编的共同起点。

## 8. 检索词必须来自"题面字面"（②循环论证的治法）

- 检索词必须是**题面的模式**，而非**我猜的人名／其亲属／其事件**。
- 反例（正解＝孟昶，答成汉文帝刘恒）：自以为"从题面词出发"，实际搜的是「薄姬 魏豹」「博局 吴太子」「代王 薄太后」——
  **每一条都是"指向我已选定答案"的关联词**，当然条条命中，于是拿答案搜答案、再拿搜到的东西证明答案。
- 正解做法：本题②「生母原是另一个势力主公的妻妾」应搜该**模式**（"本庄宗嫔御，以赐知祥"），**不许**搜"薄姬 魏豹"。
- ⚠ **四锚自查的检索词同样必须来自题面**，否则四锚会被"已选答案"污染，跑成"给已选答案找证据"。

## 9. 交付两形态（硬条件）

- ① **给出人名** ⇒ 必须**逐条全中**并**显式声明「无不符」**。
- ② **答「无法唯一确定」** ⇒ 必须**列候选与各自出局条数**。
- ⚠ 出现「不符／未见／未载／相反／存疑」等字样，**却仍给出具体人名 ⇒ 不合格**——**「本库未载」也算不符：无法证实即不得作答**。
- ⚠ 出现「宜按…理解／题面或有误／需宽松解读」等**替题面打补丁**的措辞 ⇒ 不合格。
- **交付前必跑** `python tools\check_guess.py <答案.txt>`（**rc=1 即改答形态②**）。

## 10. 工具速查

```
python tools\rag.py 谜 羯人 门臣祭酒 "当并驱于中原"   # 线索 → 候选（全部出自语料原文，附锚度）
python tools\rag.py 对照 石勒 "当并驱于中原" 羯人      # 候选 × 线索逐条共现 ✔／✗／△ ＋ 反证栏
python tools\rag.py 轻佻 --top 0 --excerpt 60          # 穷举一个硬特征词的全部出处（默认只给 8 段）
python tools\rag.py locate 张居正 --first              # 有没有开传式起句、从哪卷哪行读起
python tools\rag.py verify 答案.txt                    # 交付前核验：引文／书名／卷号／说话人／字号
python tools\check_guess.py 答案.txt                   # 交付闸：形态①／②是否合规（rc=1 不合格）
python tools\rag.py <人名> --fast                      # 有名字时的正路：★本传 + 证据块
```

- ⚠ **`谜` 的检索词表本身也曾漏人**：早期表里只写「王|帝|皇|太子」，于是不含这些字的「**徽宗**」根本进不了候选——
  而章惇谓其"轻佻不可以君天下"正是《宋史·卷二十二》的原话。**候选栏空 ≠ 库里没有**；这也是
  "选题面独有引语"比"选身份类字眼"更稳的原因。
- **单轮筛选后直接定案＝不合格**：筛选一次就收工，等于把"其余合格者"这一半论证整个丢掉。

同一形态还有一条更早的翻车：把**石勒**的特征（羯人／曾为奴／听人读《汉书》／"当并驱于中原"／胡人辞讼归门臣祭酒）
整段安到**拓跋珪**头上（实为北魏太祖道武皇帝，代国世子出身）——**由"罗列特征 → 凭记忆找相似者"反推，一律算未查**。
