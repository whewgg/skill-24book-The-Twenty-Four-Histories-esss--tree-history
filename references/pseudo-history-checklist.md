# 辨伪手册：伪造对话／伪语录（"这段历史是真的吗"）

> 适用：用户贴来一段"历史对话""古人语录"，问**"历史上有这回事吗"**；或想让你把这类内容接着写完。
> 本文件展开 `SKILL.md` 铁律第 7 条（辨伪），六查＋五型伪史＋答复三段式的细则都在这里。**核心动作只有一个：回库检索，不凭印象判真假。**
> 附完整示范见文末「案例：沈括访王安石」。

---

## 1. 为什么必须有这套流程

"AI 编一段看起来很像史的对话"是高频失效模式，而它**比普通错误更危险**：

- 它不违反语法、不出现冷僻名词、读起来甚至很有"史料感"——没有可触发的警报；
- 它往往**半真半假**：真实事件、真实官名、真实年号，缝在错的人、错的时间、错的关系上；
- 一旦有人据此转述，就变成了"史书上说…"。

因此判据不能是"读起来像不像"，只能是**能不能回指到卷次行号**。

## 2. 六查（按序做，任何一查落空都要记下）

| # | 查什么 | 怎么查 | 落空意味着 |
| --- | --- | --- | --- |
| ① | **人有没有** | `python tools\rag.py locate <人名>` → 有本传则 `rag.py locate <人名> --source index` 取卷次 | 正史无此人／无传，则整段无从谈起 |
| ② | **关系对不对** | 两人是否同卷、同现；两传互见 | 若史载关系与文本相反 → **文本必伪**（这是最强的判据） |
| ③ | **事有没有** | 关键词 Grep 该传全文（如"新法""免役""青苗"） | 事无载，则对话无载体 |
| ④ | **立场对不对** | 史载此人对此事的实际态度 | 立场相反 = 伪（见案例） |
| ⑤ | **文体对不对** | 见第 3 节「正史对话文体判据」 | 文体本身异常，先默认可疑 |
| ⑥ | **制度对不对** | 官名／地名／年号是否当世用词（见 `dynasty-disambiguation.md`） | 时代错置 = 伪 |

第 ⑥ 项举例：宋代无"从外地调人来执行"这种当代治理话术；"提举官"是宋代实有官名，"空降""异地任职"不是。

## 3. 正史对话文体判据（本手册最硬的一条知识）

**正史（本纪、列传）里的对话长这样：**

1. **君臣奏对**为主：「帝问…对曰…」「上曰…安石对曰…」（如宋史 327·15 神宗问为治所先，安石对"择术为先"）；
2. **使节应对**：「使者…曰」（如宋史 331·109 沈括对契丹相杨益戒："师直为壮，曲为老"）；
3. **僚属问对**：「X 问曰…括曰…」（如宋史 331·111 吴充问免役法）——**问者通常是宰相、上司，且多发生在公署**；
4. 对话**短、有明确政务议题、可挂到具体年份或职任上**。

**正史基本不载：**
- 两人**私下**的密谈长对话；
- "你问我答、层层递进、最后揭出道理"的**辩论体**（那是诸子、史论、影视剧的写法）；
- 无第三人在场的家访、闲谈、密室。

> **操作判据**：看到「某人去拜访某人，两人讨论某事，A 说…B 说…A 又说…」这种层层推进的复式对话结构，**先默认它可疑**，再回库查。真正的正史对话极少有这个形状。

长对话体的常见真实来源（都不是本库的 27 部正史）：《贞观政要》《世说新语》《国语》《战国策》式子书；宋元明清**笔记**（《涑水记闻》《邵氏闻见录》《元祐补录》）；晚明**公案小说**（《海公案》）；以及**现代演绎与 AI 生成**。

## 4. 常见伪史五型（附本例）

| 类型 | 特征 | 本案对应 |
| --- | --- | --- |
| **现代议题古装化** | 关切点、话术是当代的 | "从外地调人来执行"＝空降／异地任职的当代治理话术 |
| **关系倒置** | 人物立场与史载相反 | 史载沈括「希安石意」（迎合）、被劾「反覆」；图里成了质疑者 |
| **错位拼接** | 真史实缝在错的人身上 | 确有其事的是「遣提举官四十余辈，颁行天下」（327·21），但那是王安石设司推行，与沈括的对话无关 |
| **半真半假** | 一句真、一句编 | "沈括关心穷百姓"**有史实影子**——但那是对**吴充**说的（331·111），且王安石当时已去位 |
| **无出处** | 全程无书名卷次 | 图里一条出处都没有——这本就是伪史的第一体征 |

**记住：半真半假最难识破，也最该用六查。** 一读之下"像"的部分会让人放下戒备。

## 5. 答复格式（三段式，缺一段都不合格）

1. **结论先行**：正史**无此记载**（明确说"《宋史》不载"），不用"大概／可能／似乎"。
2. **史实锚点**：给出最接近的真实记载，**照录原文并注《书名·卷次·篇名》**——这一步把"没有"变成"有的是这件事"。
3. **差异点明**：指出文本与史实的**具体**冲突处（关系相反／时间错位／用词为当代语），不要只说"不准确"。

> 禁止：① 只说"这是假的"就完事；② 因为"内容有道理"就默认它有史料依据；③ 用别的书的记忆来补（如拿《宋史》以外的印象替《宋史》背书）。

若用户接着要"照这个继续写"——那已转入创作，走 `SKILL.md`「写史与改稿（双闸）」，且必须标注"虚构"。

## 6. 命令模板

```bash
PY="C:/Users/25284/.workbuddy/binaries/python/versions/3.13.12/python.exe"

$PY tools/rag.py locate 沈括                          # ① 人有没有、在哪几卷
$PY tools/rag.py locate 王安石 --count book           # ② 关系的史料权重
$PY tools/rag.py locate 沈括 --source index           # 本传入口
# ③ 事有没有：直接 Grep 该书本卷，例如
#    data\20宋史文白\现代文\331_卷三百三十一·列传第九十.md（沈括本传，97–119 行）
$PY tools/factcheck.py 稿件.txt --person 沈括  # 机械拦截（有事实卡时）
```

**有事实卡的人物，直接用 `factcheck.py`**：它会按 ②④ 的思路报出伪造关系与伪造话术，退出码 1 即"必须改"。

## 7. 案例：沈括访王安石（用户实测样本，2026-09-22）

**样本内容**（网络／AI 流传的"沈括拜访王安石论新法"对话）：王安石坚称新法利民不可动摇，沈括转述百姓更穷，王安石答"换掉执行的人"，最后说"从外地调人来执行"。

**核对结果：正史无此记载。** 六查逐项：

| 查 | 结果 | 出处 |
| --- | --- | --- |
| ① 人 | 沈括有传，**非独立传**，附于从兄沈遘传末（"括字存中"起） | 宋史 331·97–119 |
| ② 关系 | **相反**。史载「王安石主景温，**括希安石意**」——沈括是迎合王安石的一方；安石去位后他改口主张罢官卖，被蔡确劾「反覆」「首鼠乖剌，阴害司农法」 | 宋史 181·87、177·81、331·113 |
| ③ 事 | 全库无"沈括与王安石论新法"的记载。沈括本传中唯一涉及免役法的对话，对象是**吴充**（时王安石已去位） | 宋史 331·111 |
| ④ 立场 | 沈括对免役法的实际表态：抱怨者"特士大夫与邑居之人习于复除者尔，无足恤"，但"微户本无力役而亦使出钱，则为可念" | 宋史 331·111 |
| ⑤ 文体 | 复式辩难长对话，非正史体裁 | 见第 3 节 |
| ⑥ 制度 | "从外地调人来执行"为当代话术；宋代对应做法是「遣提举官四十余辈，颁行天下」 | 宋史 327·21 |

**半真的那一半**：沈括确实关心过"微户亦出钱"的负担（331·111），也确有"派官下去推行新法"的史实（327·21）——错的是把这两件事缝进了不存在的对话、且把人物的立场对调了。

**可引的原文（照录）**：

> 「王安石去位，吴充为相，沈括献议莫若稍变役法，杂以差徭为便。御史知杂蔡确言括反覆，贬括知宣州。」
> ——《宋史·卷一百七十七·志第一百三十》

> 「沈括为三司使，不能夺。王安石主景温，括希安石意，言通商岁失官卖缗钱二十余万。安石去位，括在三司，乃言官卖当罢。」
> ——《宋史·卷一百八十一·志第一百三十四》

**机械核查**：`factcheck.py 稿件 --person 沈括` 对该样本报 2 处 FAIL（"沈括去拜访王安石"、"换一批人"），退出码 1。事实卡见 `tools/facts/沈括.md`、`tools/facts/王安石.md`。
